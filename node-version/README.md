# 秒发卡铺 —— 卡密自动发货商店

高颜值发卡网：店面（发货凭据设计）+ 管理后台，对接 **V免签** 个人收款，付款后自动发货。

## 快速开始

```bash
# 需要 Node.js >= 22.13（内置 SQLite，无需安装数据库）
npm install
cp .env.example .env   # 填写配置
npm start
```

- 店面：`http://127.0.0.1:3789/`
- 后台：`http://127.0.0.1:3789/admin`（默认密码见 `.env`，**务必修改**）

## 配置（.env）

| 变量 | 说明 |
| --- | --- |
| `PORT` | 服务端口 |
| `BASE_URL` | 对外地址（拼 V免签 回调用，上线改域名，末尾不带斜杠） |
| `ADMIN_PASSWORD` | 后台密码 |
| `SESSION_SECRET` | 会话签名密钥（≥16 位随机串） |
| `VMQ_URL` | V免签地址，如 `http://127.0.0.1:8000` |
| `VMQ_KEY` | V免签 商户通讯密钥（只存服务端） |
| `PRICE_JITTER` | `1` = 同价待支付订单自动加 0~2 分避免 V免签 并发冲突 |

## V免签 对接

按 szvone/vmqphp 商户 API 实现：

- **下单**：`POST {VMQ_URL}/submit.php`，`sign = md5(payId + param + type + price + key)`
- **回调**：`GET {BASE_URL}/vmq/notify`，验签 `md5(payId + param + type + price + reallyPrice + key)`，通过后原子出库一张卡密并标记发货；验签失败返回 403
- 支付完成跳转 `/pay.html?order=订单号`，买家可随时轮询取货；「我的订单」支持订单号精确查单，或用收件邮箱查回该邮箱下全部订单（最多 20 笔，按时间倒序）；「我的订单」支持订单号精确查单，或用收件邮箱查回该邮箱下全部订单（最多 20 笔，按时间倒序）
- 若你的 V免签 版本签名规则不同，改 `server.js` 里的 `sign` 计算处即可

## 安全设计

- V免签 密钥仅存服务端，前端永远接触不到；回调强制验签（timing-safe 比较）
- 订单号 = 时间戳 + 128bit 随机，不可枚举；卡密只在订单发货后返回给持单号者
- 管理员密码 constant-time 比较；会话为 HMAC 签名的 12 小时令牌
- 全局限流（按 IP）、请求体 10kb 上限、输入长度校验、库存原子扣减（防并发超卖）
- 45 分钟未支付订单自动失效；回调幂等（重复通知不重复发货）

## 后台功能

- **总览**：今日收款/订单/待支付/在库 KPI，14 天收款与订单趋势，库存告急条，最近订单
- **订单**：按状态筛选、搜索、一键复制卡密、删除订单
- **商品**：上架/下架、编辑名称说明价格、删除商品、卡密库（查看/搜索/筛选/翻页每条卡密）、粘贴导入（允许重复）、随机生成（指定前缀 + 数量，固定 16 位，避开 I/O/0/1，自动跳重）

首次启动自动写入 3 个示例商品与卡密，**上线前请在后台替换为真实商品**。

## 宝塔部署（Linux）

1. Node 版本管理器装 Node 22+，`pm2 start server.js --name faka`
2. 反向代理到 `127.0.0.1:3789`，`.env` 的 `BASE_URL` 改成 `https://你的域名`
3. V免签 与本站可同机部署；确保 V免签 能访问到 `{BASE_URL}/vmq/notify`
