# 秒发卡铺 · PHP 版 — 上传部署说明

这个版本专为**共享虚拟主机**（PHP + FTP）制作，不需要 SSH、不需要装任何东西。
上传后即可用。首次访问会自动建库并写入 3 个示例商品，之后在后台添加你自己的商品和卡密。

---

## 第 1 步：改配置（上传前必做）

用记事本打开 **`config.php`**，改这几项：

| 配置项 | 改成什么 |
|---|---|
| `BASE_URL` | 你的完整访问地址，例如 `http://你的域名`（末尾不要斜杠） |
| `ADMIN_PASSWORD` | 换成你自己的后台密码（现在是 `change-me-please`，**必须改**） |
| `SESSION_SECRET` | 随便一串 16 位以上的乱码（用来签登录令牌，改一次即可） |
| `VMQ_URL` / `VMQ_KEY` | 填你自己的 V免签 地址和商户通讯密钥（V免签 后台「系统设置」里可见） |

改完保存（保持 UTF-8 编码）。

## 第 2 步：FTP 上传

把**本文件夹里的所有文件**（保持目录结构）上传到主机的网站根目录（一般是 `wwwroot` 或 `public_html`）：

```
wwwroot/
├── index.html          店面
├── admin.html          后台
├── pay.html            支付页
├── api.php             程序入口
├── lib.php             公共库
├── config.php          配置（第 1 步改的就是它）
├── .htaccess           URL 重写（重要，别漏传！FTP 里注意勾选"显示隐藏文件"）
├── assets/             样式、脚本、图片
└── data/               数据库目录（含 faka.db，自动读写）
```

FTP 地址、端口、账号在你的主机面板「FTP/信息」处可见。
推荐用 FileZilla：文件 → 站点管理器 → 新站点 → 协议选 FTP，并勾选「服务器强制显示隐藏文件」以便上传 .htaccess。

## 第 3 步：绑定域名

1. 主机控制面板 →「域名绑定」→ 添加你的域名
2. 到你的域名解析处（在哪买的域名就去哪）添加解析：
   - 记录类型 `A`，主机记录 `@` 或 `www`，记录值 `你的主机IP`
3. 生效后直接访问 `http://你的域名` 即是店面，`http://你的域名/admin` 是后台

> 香港/海外主机一般不用备案，绑定即可用。

## 第 4 步：上线检查清单

依次访问验证（都正常再开始卖）：

- [ ] 打开 `http://你的域名/` 能看到店面和商品
- [ ] 打开 `/admin`，用新密码能登录
- [ ] 下单一笔 0.01 测试品，扫码支付，能自动发货
- [ ] 「我的订单」能按订单号/邮箱查到

## 第 5 步：V免签 后台设置

登录 V免签管理后台 →「系统设置」→ 把**异步回调地址**改成：

```
http://你的域名/api.php?_r=vmq%2Fnotify
```

（现在填的还是别的网址，不改的话线上只能靠轮询兜底发货，改了回调最及时。）

## 常见问题

**Q：打开报 404 / API 无响应？**
`.htaccess` 没生效。去主机面板找「伪静态」设置，把 `.htaccess` 文件里的规则粘贴进去；或者确认 `.htaccess` 确实上传了（FTP 默认可能不显示点开头的文件）。

**Q：页面报「没有启用 pdo_sqlite」？**
主机面板 →「PHP 版本」→ 换成 PHP 7.4 或更高；还不行就联系主机客服开启 `pdo_sqlite` 扩展。

**Q：下单报「支付通道尚未配置 / 通道不可用」？**
`config.php` 里 `VMQ_URL`/`VMQ_KEY` 没填对，或主机无法访问 V免签 地址（某些主机会限制外链请求，联系客服确认允许 curl 外访）。

**Q：以后想改商品/卡密？**
直接在后台操作，不用重新上传。数据库就是 `data/faka.db`，想备份就 FTP 把它下载下来。

**Q：本地怎么跑？**
本文件夹自带 `router-dev.php`（仅供本地 `php -S localhost:8080 router-dev.php` 测试用，上传到主机不需要它）。
